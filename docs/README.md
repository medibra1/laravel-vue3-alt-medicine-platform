# Documentation

Ce dossier centralise la documentation technique du projet — **à tenir à
jour à chaque changement de schéma ou d'architecture**, pas seulement au
moment où un domaine est construit.

- [`schema-donnees.md`](./schema-donnees.md) — schéma complet de toutes
  les tables, domaine par domaine, avec les décisions et le raisonnement
  derrière chaque choix non évident (préfixage, traductions, statuts...).
- [`structure-ddd.md`](./structure-ddd.md) — organisation des dossiers
  Domain-Driven, conventions de code (nommage, services, Concerns).

`CLAUDE.md` (racine du projet, gitignoré) reste le point d'entrée pour
le contexte de continuité entre sessions Claude Code — il renvoie vers
ces documents plutôt que de dupliquer leur contenu.
